# Hekus DoorPhone Integration for Home Assistant

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)

Интеграция для управления домофонами Ufanet через Home Assistant.
Интеграция использует ["Умный дом от Ufanet"](https://dom.ufanet.ru/).
Используется открытое API для управления домофонами: https://secretapi.ufanet.ru/ru/Intercom

## Возможности

- Авторизация по номеру договора и паролю
- Автоматическое обнаружение всех доступных домофонов
- Замок (lock) для открытия двери каждого домофона
- Датчик последнего вызова с историей звонков для каждого домофона
- Изображение с превью последнего вызова для каждого домофона
- Защита от повторного открытия двери
- Поддержка нескольких домофонов в одном аккаунте

## Установка через HACS

1. Добавьте этот репозиторий в HACS как пользовательский репозиторий
2. Найдите "Hekus DoorPhone" в списке интеграций
3. Нажмите "Установить"
4. Перезагрузите Home Assistant

## Ручная установка

1. Скопируйте папку `hekus_doorphone` в директорию `custom_components` вашего Home Assistant
2. Перезагрузите Home Assistant
3. Добавьте интеграцию через интерфейс настроек

## Настройка

1. Перейдите в Настройки → Устройства и службы → Добавить интеграцию
2. Найдите "Hekus DoorPhone"
3. Введите номер договора и пароль от вашего аккаунта Ufanet
4. Интеграция автоматически обнаружит все доступные домофоны

## Сущности

Сущности создаются отдельно для каждого домофона договора:

- Замок «Door lock» — открытие двери; сущность недоступна, если домофон
  заблокирован в аккаунте Ufanet;
- Датчик «Последний вызов» (`sensor`) — время последнего вызова домофона и
  сведения о его последних звонках;
- Изображение «Превью последнего вызова» (`image`) — кадр с камеры домофона
  в момент последнего звонка.

История звонков привязана к конкретному домофону, а не ко всему договору:
у каждого домофона свой датчик и своё превью, поэтому несколько домофонов в
одном аккаунте не мешают друг другу.

## Поддерживаемые домофоны

Интеграция работает с домофонами, поддерживаемыми сервисом Ufanet:
- Домофоны в подъездах
- Калиточные домофоны
- Другие устройства, доступные в личном кабинете Ufanet

## Логирование

Для отладки добавьте в `configuration.yaml`:

```yaml
logger:
  logs:
    custom_components.hekus_doorphone: debug
```

## Диагностика

В карточке интеграции (Настройки → Устройства и службы → Hekus DoorPhone) доступна
выгрузка диагностики. Пароль в выгрузку не попадает.

## Проверка API без Home Assistant

Скрипт `scripts/ufanet_api_example.py` авторизуется тем же способом, что и интеграция,
и печатает список домофонов, камер видеонаблюдения с RTSP-ссылками и последние вызовы
домофона со ссылками на превью и запись.
Установленный Home Assistant не нужен — достаточно зависимостей клиента:

```powershell
pip install aiohttp pydantic
```

Учётные данные берутся из переменных окружения:

```powershell
$env:UFANET_CONTRACT="номер договора"
$env:UFANET_PASSWORD="пароль"
python scripts/ufanet_api_example.py
```
