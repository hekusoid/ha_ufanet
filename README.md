# Hekus DoorPhone Integration for Home Assistant

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)

Интеграция для управления домофонами Ufanet через Home Assistant. 
Интеграция использует ["Умный дом от Ufanet"](https://dom.ufanet.ru/) 
Используется открытое апи по упраленияб домофонами https://secretapi.ufanet.ru/ru/Intercom

## Возможности

- Авторизация по номеру договора и паролю
- Автоматическое обнаружение всех доступных домофонов
- Замок (lock) для открытия двери каждого домофона
- Датчик последнего вызова с историей звонков
- Защита от повторного нажатия
- Поддержка нескольких домофонов в одном аккаунте

## Установка через HACS

1. Добавьте этот репозиторий в HACS как пользовательский репозиторий
2. Найдите "Hekus DoorPhone" в списке интеграций
3. Нажмите "Установить"
4. Перезагрузите Home Assistant

## Ручная установка

1. Скопируйте папку `hekus_doorphone` в директорию `custom_components` вашего Home Assistant
2. Перезагрузите Home Assistant
3. Добавьте интеграцию через интерфейс настроек

## Настройка

1. Перейдите в Настройки → Устройства и службы → Добавить интеграцию
2. Найдите "Hekus DoorPhone"
3. Введите номер договора и пароль от вашего аккаунта Ufanet
4. Интеграция автоматически обнаружит все доступные домофоны

## Сущности

Для каждого домофона создается:
- Замок «Door lock» — открытие двери, повторное открытие ограничено 8 секундами, сущность недоступна, если домофон заблокирован в аккаунте Ufanet

## Поддерживаемые домофоны

Интеграция работает с домофонами, поддерживаемыми сервисом Ufanet:
- Домофоны в подъездах
- Калиточные домофоны
- Другие устройства, доступные в личном кабинете Ufanet

```yaml
logger:

```

## Диагностика

В карточке интеграции (Настройки → Устройства и службы → Hekus DoorPhone) доступна
выгрузка диагностики: список домофонов из API, состояние координатора и интервал
опроса, а также последние вызовы из истории. Пароль в выгрузку не попадает.

## Камеры видеонаблюдения (API)

Клиент API умеет получать камеры аккаунта: `UfanetIntercomAPI.get_cameras()` возвращает
список моделей `Camera`. Помимо полей ответа (`number`, `title`, `address`, `servers`,
`token_l`, `token_r`, `type`, `inactivity_period`) у модели есть вычисляемые свойства:

- `rtsp_url` — ссылка на живой поток
  `rtsp://{servers.domain}/{number}?token={token_l}&tracks=v1a1`
  (`tracks=v1a1` запрашивает у Flussonic видео- и аудиодорожку);
- `screenshot_url` — актуальный снапшот
  `https://{servers.screenshot_domain}/api/v0/screenshots/{number}~600.jpg?token={token_l}`.

Что важно при использовании ссылок:

- `token_l` — живой JWT камеры с ограниченным сроком жизни, поэтому ссылку нужно
  периодически обновлять повторным `get_cameras()`; частые запросы списка камер Ufanet
  ограничивает (HTTP 429), так что обновлять стоит не чаще раза в несколько минут;
- `token_r` — токен записи (архив), для живого RTSP-потока он не используется;
- часть полей у отдельных камер может быть `null` (`servers`, `token_r`, координаты,
  `title`, `address`), поэтому оба свойства возвращают `None`, если ссылку построить нельзя.

Сущностей `camera` интеграция пока не создаёт — это только слой доступа к API.

## Проверка API без Home Assistant

Скрипт `scripts/ufanet_api_example.py` авторизуется тем же способом, что и интеграция,
и печатает список камер видеонаблюдения с RTSP-ссылками и последние вызовы домофона
со ссылками на превью и запись.
Установленный Home Assistant не нужен — достаточно зависимостей клиента:

```powershell
pip install aiohttp pydantic
```

Учётные данные берутся из переменных окружения:

```powershell
$env:UFANET_CONTRACT="номер договора"
$env:UFANET_PASSWORD="пароль"
python scripts/ufanet_api_example.py
```
