# Hekus DoorPhone Integration for Home Assistant

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)

Интеграция для управления домофонами Ufanet через Home Assistant. 
Интеграция использует ["Умный дом от Ufanet"](https://dom.ufanet.ru/) 
Используется открытое апи по упраленияб домофонами https://secretapi.ufanet.ru/ru/Intercom

## Возможности

- Авторизация по номеру договора и паролю
- Автоматическое обнаружение всех доступных домофонов
- Замок (lock) для открытия двери каждого домофона
- Датчик последнего вызова с историей звонков для каждого домофона
- Изображение с превью последнего вызова для каждого домофона
- Защита от повторного нажатия
- Поддержка нескольких домофонов в одном аккаунте

## Установка через HACS

1. Добавьте этот репозиторий в HACS как пользовательский репозиторий
2. Найдите "Hekus DoorPhone" в списке интеграций
3. Нажмите "Установить"
4. Перезагрузите Home Assistant

## Ручная установка

1. Скопируйте папку `hekus_doorphone` в директорию `custom_components` вашего Home Assistant
2. Перезагрузите Home Assistant
3. Добавьте интеграцию через интерфейс настроек

## Настройка

1. Перейдите в Настройки → Устройства и службы → Добавить интеграцию
2. Найдите "Hekus DoorPhone"
3. Введите номер договора и пароль от вашего аккаунта Ufanet
4. Интеграция автоматически обнаружит все доступные домофоны

## Сущности

Для каждого домофона создаются:
- Замок «Door lock» — открытие двери, повторное открытие ограничено 8 секундами, сущность недоступна, если домофон заблокирован в аккаунте Ufanet;
- Датчик «Последний вызов» (`sensor`) — время последнего вызова этого домофона и список его последних звонков;
- Изображение «Превью последнего вызова» (`image`) — кадр с камеры домофона в момент последнего звонка.

Отдельного устройства для личного кабинета dom.ufanet.ru больше нет: история
вызовов привязана не ко всему договору, а к конкретному домофону.

### Как вызовы привязываются к домофону

Ufanet отдаёт историю звонков по всему договору, без фильтра по домофону.
Интеграция сопоставляет вызов с домофоном по номеру камеры: если `camera_number`
вызова совпадает с `cctv_number` домофона, вызов относится к этому домофону.
Сравнение не зависит от регистра и лишних пробелов.

Следствия:

- если в аккаунте несколько домофонов, у каждого свой датчик и своё превью;
- звонок с камеры, которой нет среди домофонов договора, не показывается ни у
  одного домофона (включите debug-логи, чтобы увидеть такие вызовы);
- если один и тот же `cctv_number` встречается у нескольких домофонов (общая
  камера), их датчики покажут один и тот же вызов;
- у домофона без `cctv_number` датчик и изображение не создаются.

### Датчик «Последний вызов»

Состояние — время последнего вызова этого домофона (`device_class: timestamp`).

Атрибуты:

- `cctv_number` — номер камеры домофона, по которому отбираются вызовы;
- `calls_count` — сколько вызовов этого домофона попало в загруженную историю;
- `calls_total` — сколько всего вызовов в истории Ufanet по договору;
- `recording_url` и `preview_url` — ссылки на запись и превью последнего вызова;
- `calls` — вызовы этого домофона из загруженной истории (до
  `CALL_HISTORY_PAGE_SIZE` вызовов на весь договор), каждый со своими `uuid`,
  `called_at`, `address`, `porch`, `flat`, `house_id`, `camera_number`,
  `skud_mac`, `timezone`, `recording_url`, `preview_url`. Ссылки на запись и
  превью запрашиваются только для `CALL_HISTORY_LINKED_CALLS` (10) самых свежих
  вызовов домофона, чтобы не тратить лишние запросы к API.

### Изображение «Превью последнего вызова»

Состояние — время последнего вызова (`image_last_updated`), поэтому при новом
звонке карточка в интерфейсе сама перезапрашивает картинку. Кадр — то самое
превью, ссылка на которое есть в атрибуте `preview_url` датчика этого же
домофона: интеграция скачивает его один раз на вызов и держит в памяти, потому
что ссылка временная, а превью конкретного звонка не меняется. Живого потока и
записи у изображения нет — это статичный кадр момента звонка,
`camera.play_stream` к нему неприменим.

Если домофон ещё ни разу не звонил, сущности остаются без состояния. После
неудачного скачивания превью повторная попытка делается не раньше чем через
30 секунд, а при новом звонке — сразу.


## Поддерживаемые домофоны

Интеграция работает с домофонами, поддерживаемыми сервисом Ufanet:
- Домофоны в подъездах
- Калиточные домофоны
- Другие устройства, доступные в личном кабинете Ufanet

## Логирование

Для отладки добавьте в `configuration.yaml`:

```yaml
logger:
  logs:
    custom_components.hekus_doorphone: debug
```

## Диагностика

В карточке интеграции (Настройки → Устройства и службы → Hekus DoorPhone) доступна
выгрузка диагностики: список домофонов из API и их номера камер, состояние
координатора и интервал опроса, а также распределение вызовов по домофонам.
Пароль в выгрузку не попадает.

## Проверка API без Home Assistant

Скрипт `scripts/ufanet_api_example.py` авторизуется тем же способом, что и интеграция,
и печатает список камер видеонаблюдения с RTSP-ссылками и последние вызовы домофона
со ссылками на превью и запись.
Установленный Home Assistant не нужен — достаточно зависимостей клиента:

```powershell
pip install aiohttp pydantic
```

Учётные данные берутся из переменных окружения:

```powershell
$env:UFANET_CONTRACT="номер договора"
$env:UFANET_PASSWORD="пароль"
python scripts/ufanet_api_example.py
```
